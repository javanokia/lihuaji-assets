# AR 单纹样示例素材

这四张透明 PNG 来自用户在本项目对话中提供的纹样参考截图。用户确认已取得原作者许可。

图片经过 AI 辅助重绘与清理：移除了截图文字、水印、黑色画布及左上角的原物照片，并保留主体配色与构图作为梨花季的 AR 视觉示例。它们不是原图的像素级抠图、馆藏原件扫描或经专家复核的历史复原。

识别卡位于 `../markers/`。识别卡用于 MindAR 图片追踪；透明图案用于应用内的 2.5D 浅浮雕、光点与轻微动画展示。当前没有把它们拆成独立纹样部件或真实 3D 网格。

标题依据截图中的文字转录；具体历史年代、器物名称和纹样归属尚未独立核实。
